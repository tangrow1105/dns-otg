DNS On The Go

Privacy policy

Last updated: 7 October 2026

Summary

DNS On The Go ("DNS OTG", "the app") does not collect, store or share any of your data on servers of its own. There are no ads, no analytics and no tracking.

What the app stores on your phone

The app saves the Control D API token you sign in with, encrypted with the Android Keystore, and a few display preferences such as the theme and your last selected filters. This stays on your phone and is removed when you sign out or uninstall the app.

Who the app talks to

The app only connects to Control D's own services (controld.com and its subdomains, such as api.controld.com) to show and change your Control D account: profiles, endpoints, rules, statistics, logs and billing details. What Control D does with that data is covered by Control D's own privacy policy.

When you use "Sign in with Control D", the sign-in page is Control D's website, shown inside the app. The app creates an API token for itself, then clears that web session.

Copies installed from GitHub (not from Google Play) also check GitHub's public releases (api.github.com) for a newer version when the app opens. That request carries no account data; GitHub sees it like any web request. Copies installed from Google Play don't make this check, because Google Play handles their updates.

Permissions

The app uses the internet permission to reach Control D (and, for GitHub installs, to check GitHub for updates). It reads the clipboard only to offer pasting an API token you copied.

Children

The app isn't directed at children under 13.

Changes

If this policy changes, the new version will be posted on this page with a new date.

Contact

Questions: open an issue at github.com/tangrow1105/dns-otg/issues.

DNS On The Go is an unofficial app, not affiliated with Control D.
